**Software developer focused on backend/full-stack engineering.**

I enjoy building the logic and infrastructure behind applications, from APIs and state management to the details that make software easier to maintain. I'm currently working on a chess web application and contributing to open-source software.

## Projects

### [Chess Web](https://github.com/Tacticaltacos77/Chess-Web)
*Django · Django REST Framework · PostgreSQL · JavaScript · Vite*

A full-stack chess project with user accounts, an interactive board, and a puzzle challenge system. 

- Built a Django API for retrieving chess puzzles by difficulty from a database.
- Implemented browser-based chessboard interactions, legal-move handling, promotion, and customizable board styles.
- Continuing work on the online multiplayer.

### [Python Chess Library](https://github.com/Tacticaltacos77/Chess)
*Python · pytest*

A chess rules library written from scratch, with legal move generation, game-state management, FEN support, and reversible moves. It handles special moves, checks, checkmate, and draw conditions, with automated tests for the rules and edge cases.

### [Caching Reverse Proxy](https://github.com/Tacticaltacos77/simple_reverse_proxy)
*Python · aiohttp*

An asynchronous HTTP reverse proxy with an in-memory LRU cache, configurable expiration, and support for upstream `Cache-Control` directives.

### [Hardware Monitoring MCP](https://github.com/Tacticaltacos77/Hardware-Monitoring-MCP)
*Python · MCP · psutil*

An MCP server that samples process-level CPU and memory usage over time to help investigate intermittent performance problems.
